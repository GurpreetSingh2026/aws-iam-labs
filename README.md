# AWS IAM Lab

## Objective

Learn AWS account security and Identity & Access Management (IAM).

## Tasks Completed

- Created AWS account
- Logged in as Root User
- Enabled MFA for Root User
- Created IAM User
- Explored IAM Dashboard
- Reviewed AWS security recommendations

## Key Concepts Learned

### IAM User
Represents an individual user who can sign in to AWS.

### IAM Group
A collection of users sharing permissions.

### IAM Policy
Defines permissions granted to users, groups, or roles.

### IAM Role
Temporary permissions assigned to AWS services or users.

### MFA
Multi-Factor Authentication adds an additional layer of security by requiring a verification code from an authenticator application.

## Lessons Learned

- Root account should only be used for account-level administration.
- IAM users should be used for daily AWS activities.
- MFA is critical for protecting AWS accounts.
- AWS console interfaces change frequently, but core concepts remain the same.
